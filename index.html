How it works

1. Open it on both devicesBoth on the same Wi-Fi or phone hotspot. They find each other automatically.
2. Pick a device and filesTap the other device, choose photos, videos or any files.
3. Accept on the other deviceThe receiving device asks to accept or decline. Accept, and the files arrive.

Installing

Android
  1. Open the downloaded .apk.
  2. If asked, allow your browser or file manager to install unknown apps.
  3. Open Stagshare and allow notifications, so transfers keep going in the background.
Mac
  1. Open the .dmg and drag Stagshare into Applications.
  2. The first time, right-click Stagshare in Applications and choose Open (it isn't from the App Store).
  3. Allow it to find devices on your local network when macOS asks.
Windows
  1. Unzip the download and open Stagshare\stagshare.exe.
  2. If Windows says "unknown publisher", click More info → Run anyway.
  3. When Windows Firewall asks, click Allow, or other devices can't send to you.
Ubuntu / Linux
  1. Extract it: tar -xzf Stagshare-1.1.0-linux-x64.tar.gz
  2. Run ./Stagshare/stagshare
  3. Devices are found through Avahi (on by default in Ubuntu). If none show up, use Connect by address.

Stagshare asks for an access code on first launch. Ask the person who shared this page for it.
